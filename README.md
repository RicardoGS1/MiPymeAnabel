![image](https://github.com/user-attachments/assets/20571454-e5c8-42b5-9938-829d61ab7f1a)# Anabella's Shop

Es una aplicación desarrollada con Kotlin Multiolatform para poder ser desplegada para Android e iOS. La aplicación permite a los usuarios realizar pedidos de productos y saber el estado de sus ordenes. 

## Características
1. Permite a los usuarios ver y ordenar compras de los productos del cliente.
2. Registrarse mediante correo y contraseña para que persistan sus datos y manejar sus ordenes desde el servidor.
3. Ser notificados del estado de sus ordenes de compra.
4. Obtener el resumen de sus pedidos actuales.
5. Llevar el registro de todas sus operaciones.
6. Especificar la fecha en la que desea recoger el pedido.
7. Un diseño simple y moderno.
8. Compatibilidad con modo oscuro.

## Tecnologias
1. Desarrollada en Kotlin Multiplatform.
2. JetPack Compouse
3. inyección de Dependencias (Koin).
4. arquitectura MVVM, Clean Architecture.
5. Notificaciones FCM.
6. Base de datos FIRESTORE.
7. Autenticación FIREBASE AUTH.
8. ROOM.
9. LLamadas al servidor mediante KTOR.
